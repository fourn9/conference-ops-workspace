# Application-ready project description

## Short English version

I built an AI-assisted workspace for conference operations, organizing research, speaker and sponsor workflows, communication drafts, and decision history. I also implemented a session-journal prototype with transcript extraction, background summarization, indexing, and recall to preserve the distinction between approved decisions and unresolved ideas. This public case study includes a new synthetic demo of decision-aware task handoffs.

Project: https://github.com/fourn9/conference-ops-workspace
